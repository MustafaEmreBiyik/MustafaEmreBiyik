#### 🛡️ Real-Time Network Intrusion Detection System
Production-grade NIDS on a Dockerized **Kafka** streaming pipeline.
- Benchmarked **5 ML/DL architectures** (XGBoost, Random Forest, Decision Tree, BiLSTM, LSTM) on **2.8M+ flows** → **98.88% accuracy**, **0.999 ROC-AUC**
- Real-time dashboard with **SHAP** explainability, dynamic model reloading, and automated firewall threat mitigation
- Scapy → CICFlowMeter pipeline (78→20 features) → **0.008 ms** inference latency at **126K+ predictions/sec**
- 📄 **Paper submitted to SIU 2026 (IEEE)** — under review
- **Stack:** Python · Kafka · Docker · XGBoost · TensorFlow · Scapy
- 🔗 `https://github.com/MustafaEmreBiyik/<network-ids-repo>`

#### 🦷 Oral Pathology Assessment Platform (DentalAI)
Full-stack clinical learning platform for dental students.
- **MedGemma** medical LLM + rule-based validation for AI-powered diagnostic feedback
- Adaptive learning engine using **Item Response Theory (IRT)** with LSTM/XGBoost to adjust case difficulty
- **200+ patient scenarios** with progressive disclosure and multi-modal analysis of dental radiographs
- **Stack:** React · Next.js · FastAPI · PostgreSQL · MedGemma
- 🔗 `https://github.com/MustafaEmreBiyik/DisHekimligiAI`
